# Navajo Code Talkers

The **Navajo Code Talker Program** of the [[united-states-marine-corps|United States Marine Corps]] was established in September 1942, following a recommendation made the previous February by Philip Johnston to Major General Clayton B. Vogel, USMC, Commanding General of the Amphibious Corps, Pacific Fleet.[1]

## Origins and rationale

Johnston, the son of a missionary to the Navajo tribe, was fluent in the language, having lived among the Navajos for twenty-four years.[1] He believed that the Marine Corps' use of Navajo as a code language in voice transmission over radio and wire could guarantee communications security.[1] His rationale was that Navajo is an unwritten language, completely unintelligible to anyone except another Navajo, and that it is rich and fluent enough for code words to be devised within it for specialized military terminology.[1]

## Significance

The Badlands Brief article "Kekistani Code Talkers" presents the program as its fifth historical case study and as the secondary inspiration for the essay, praising it as a clear demonstration that entire languages can be leveraged by militaries to win a contest of power projection.[1] The title of the article draws directly on this precedent, asking whether readers fluent in the symbolic language of [[qanon|Q]] and [[covfefe|Covfefe]] constitute a comparable corps of code talkers.[1]
