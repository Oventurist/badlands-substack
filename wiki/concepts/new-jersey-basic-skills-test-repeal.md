# New Jersey Basic Skills Test Repeal for Teachers

The New Jersey basic skills test repeal removed the requirement that aspiring teachers in New Jersey pass a basic skills examination in order to be certified.[1]

## The law

Democratic Governor [[phil-murphy|Phil Murphy]] enacted Act 1669 in June as part of the state's 2025 budget, framed as a response to a teacher shortage; the law took effect on January 1, 2025.[1] Under it, individuals seeking an instructional certificate no longer need to pass the Praxis Core Test, a basic skills test in reading, writing, and math administered by the state's Commissioner of Education.[1]

The bill's sponsor, Democratic Senator Jim Beach, defended the measure when the chamber cleared it in a 34-2 vote in May 2024: "We need more teachers. This is the best way to get them."[1] The item ran as a bonus entry in the Badlands News Brief, presented without commentary as an illustration of declining institutional standards.[1]
